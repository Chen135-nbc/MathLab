# 课程数据范围与核对清单

预期来源：《MathLab 高中数学知识大纲与能力框架 V0.2.docx》。截至项目初始化时，工作区与相邻目录未找到该文件。

当前 JSON 文件建立了用户要求的五册、18 章结构。章名按常见人教 A 版目录暂列，`verified: false` 明示尚未与指定大纲核对。第一章的 1.1、1.2、1.3 和 5 个基础知识节点用于运行与持久化验证，不能视作完整课程大纲。搜索、目录树和详情只显示实际录入的知识节点。未核实章节不生成虚构小节。

核对时依次确认册次、章名、章节编号、小节名、核心知识点和排序。保留既有 ID；若发生拆分或合并，先设计迁移映射，以免笔记失去关联。可参照[人教版 A 版必修第一册教学资源](https://www.pep.com.cn/xw/zt/xkzt/gsazy/gsabx1/)和[教育部公开的课程资源目录](https://www.moe.gov.cn/jyb_xxgk/s5743/s5744/A06/202203/W020220318610109798820.pdf)进行交叉核对，最终以用户提供的大纲和实际教材为准。
