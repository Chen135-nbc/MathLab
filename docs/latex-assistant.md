# LaTeX 数学公式助手 V1.0

在 Math Notes 课程首页可打开「LaTeX 使用手册」。进入知识点笔记后，可使用「Σ 数学公式」或「LaTeX 使用手册」打开同一个助手，后者带有插入笔记操作。

## 使用

1. 在笔记中点击要插入公式的位置；也可以选中一段待替换的内容。
2. 点「Σ 数学公式」。只输入公式本身，不输入外层的美元符号。
3. 使用工具栏插入分数、根号、上下标、括号、希腊字母、集合、求和、向量、分段式和几何记号。工具栏会使用公式输入框的当前选区，模板中的示例变量可以直接修改。
4. 在手册中搜索「交集」「根号」「向量」「垂直」，或者英文术语与完整命令。「放入公式编辑位置」把条目送入公式草稿继续编辑；「插入笔记」直接使用当前选中的条目。
5. 选择行内或独立公式，确认实时效果后点「插入笔记」。原笔记选区将被替换，其余文字保留；独立公式会补上段落换行。
6. 笔记中可以使用 Cmd-Z（Mac）或 Ctrl-Z（Windows）撤销，Cmd-Shift-Z / Ctrl-Shift-Z 或 Ctrl-Y 重做。本页编辑会话最多保留 100 个撤销快照，刷新后不保留撤销历史。
7. 使用原有「保存笔记」写入 SQLite。公式助手不自动保存笔记。

手册复制的是不带 Markdown 外层分隔符的 LaTeX 原始代码。剪贴板权限受限时会提示手动复制。Tab 可以浏览操作，Esc 关闭弹窗并返回笔记编辑状态。关闭助手不会修改笔记；未插入的公式草稿会丢弃。

## 内容

静态目录共 56 项，包含基础数学输入 11 项、集合与逻辑 9 项、方程与不等式 5 项、函数与数列 8 项、三角函数 4 项、平面几何 5 项、平面向量 4 项、解析几何 7 项、立体几何 3 项。

每项包含稳定 ID、中文名称、别名、分类、LaTeX 源代码、示例和简短说明。基础条目解释了 {} 分组、反斜杠命令、^ 上标、_ 下标和多行对齐。英文检索匹配完整别名或命令，避免把 in 匹配到 sin 等无关词中。

## 实现边界

沿用 React 受控 textarea 和 KaTeX，不增加依赖、后端 API 或数据库表。LaTeX 渲染使用 trust=false、严格语法检查及展开次数和尺寸限制；错误提示保留输入，并在 KaTeX 给出位置时显示字符位置。公式本体最多 5000 字符，笔记上限沿用 100000 字符。

这是代码编辑、结构模板与实时预览工具，不是可直接拖动数学符号的所见即所得排版器。原始 LaTeX 的复杂文档环境、HTML 命令、完整 LaTeX 宏包不在支持范围。若需修改已插入的公式，选中整个 $...$ 或 $$...$$ 后打开助手；只选中公式内部的一小段会按普通选区替换规则处理。

## 验证

执行：

```bash
npm --prefix frontend test
npm --prefix frontend run build
.venv/bin/python -m pytest backend/tests -q
```

自动测试覆盖全部条目及示例的 KaTeX 渲染、中文和精确命令搜索、光标插入、选区替换、独立公式换行、Markdown 数学节点识别、撤销重做状态和持久化。浏览器手动验收应补充剪贴板权限、输入法组合输入、键盘撤销、Esc 返回以及亮暗模式。
